# Estúdio Melódico & Gerador MIDI

Aplicação interativa de teoria musical, estúdio melódico, metrônomo digital e gerador de arquivos MIDI desenvolvida em **React 18**, **TypeScript**, **Tailwind CSS** e **Web Audio API**.

## 🚀 Funcionalidades Principais

- **Escalas e Permutações Melódicas**: Suporte a diversos dicionários de escalas e ritmos customizáveis.
- **Metrônomo Digital de Alta Precisão**: Módulo sintetizado via Web Audio API com sincronização contínua baseada em `(60 / BPM) * 1000 ms` e visualizador de pulsos.
- **Visualizador de Partitura & Piano Roll**: Exibição gráfica e dinâmica das sequências de notas.
- **Exportação de Arquivos MIDI**: Gerador nativo em browser pronto para importação em DAWs (Ableton, FL Studio, Reaper, Logic, etc.).
- **Gerenciador de Acompanhamento Harmônico**: Edição e reprodução de acordes e sequências.

## 🛠️ Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
